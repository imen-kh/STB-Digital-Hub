# Berry Angular Admin Template

## 🚀 Getting Started 
Follow these steps to set up the project:

1. Navigate to your root folder
```
c:> cd berry-angular-ng-bootstrap
```

2. Install packages

```
npm install --legacy-peer-deps
```

3. Run project

```
npm run start
```
